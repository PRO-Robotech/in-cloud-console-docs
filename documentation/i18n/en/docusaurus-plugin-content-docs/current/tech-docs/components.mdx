## Component Description

- **Client (browser)**: the user interface for interacting with the system.
- **Nginx**: an L7 proxy that manages incoming request routing.
- **WEB**: the visual module responsible for rendering data and building the interface.
- **BFF**: an intermediate layer for aggregating and optimizing requests from the client.
- **Kubernetes API**: the access interface to the managed environment.
