## Описание компонентов

- **Клиент (браузер)**: пользовательский интерфейс для взаимодействия с системой.
- **Nginx**: L7-прокси, управляющий маршрутизацией входящих запросов.
- **WEB**: визуальный модуль, отвечающий за отрисовку данных и построение интерфейса.
- **BFF**: промежуточный слой для агрегации и оптимизации запросов от клиента.
- **Kubernetes API**: интерфейс доступа к управляемой среде.
